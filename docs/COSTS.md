# هزینه سرویس‌های خارجی

> اصل شفافیت: هیچ عدد دقیق قیمتی بدون بررسی منبع ادعا نمی‌شود. جدول زیر «ساختار هزینه» هر سرویس را توضیح می‌دهد؛ مبلغ روز را از سایت رسمی سرویس چک کنید.

## بدون هیچ هزینه‌ای قابل اجرا (پیش‌فرض)

| قابلیت | وضعیت |
|---|---|
| موتور امتیازدهی، ویرایشگر، نسخه‌بندی، تحلیل زنده | کاملاً داخلی — رایگان |
| گسترش/خوشه‌بندی/اینتنت کلمات کلیدی | قاعده‌محور — رایگان |
| بریف قاعده‌محور، mapping، کانیبالیزیشن | رایگان |
| سئو تکنیکال یک URL + تشخیص تکراری | رایگان (فقط شبکه) |
| Webhook، connectors، ویجت | رایگان |
| AI محلی با Ollama | رایگان (سخت‌افزار خودتان) |

## وابسته به سرویس پولی (اختیاری)

| سرویس | برای چه قابلیتی | ساختار هزینه |
|---|---|---|
| DataForSEO | SERP واقعی + حجم جست‌وجو + سختی واقعی | اعتباری (pay-per-request) — بسته‌های شارژ؛ قیمت per-call متفاوت بر اساس endpoint |
| SerpApi | SERP واقعی (جایگزین) | اشتراک ماهانه بر اساس تعداد جست‌وجو + پلن رایگان محدود |
| AI (Z.ai GLM/OpenAI/OpenRouter/Groq/DeepSeek) | تولید محتوا | pay-per-token یا سهمیه رایگان/ماهانه |
| PageSpeed Insights API | Core Web Vitals | رایگان با سهمیه؛ کلید برای سهمیه بیشتر |
| VPS/سرور | اجرای Backend | از VPS چند دلاری تا سرور تیمی |

## حداقل مسیر رایگان برای شروع واقعی

1. Backend روی VPS ارزان یا خود سرور — رایگان تا منابع خودتان.
2. AI با Ollama محلی یا مدل flash رایگان — تقریباً صفر.
3. SERP/حجم: تا وقتی کلید ندارید، سیستم شفاف «not_configured» می‌گوید و دیگر قابلیت‌ها بدون مشکل کار می‌کنند.

## کجا را باید صفر و یک کرد؟

- قبل از production: `JWT_SECRET`، `APP_ENCRYPTION_KEY` (رایگان، اجباری).
- برای تیم چندنفره: یک کلید DataForSEO کوچک بیشتر تجربه را واقعی می‌کند.
