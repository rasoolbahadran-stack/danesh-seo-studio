# راهنمای Providerهای هوش مصنوعی

هر سرویسی که API سازگار با OpenAI (`POST {baseUrl}/chat/completions`) داشته باشد کار می‌کند. تنظیم در پنل: **تنظیمات وب‌سایت → هوش مصنوعی**.

| سرویس | Base URL | مدل نمونه | هزینه تقریبی |
|---|---|---|---|
| Z.ai (GLM) | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` | مدل‌های flash ارزان/رایگان با سهمیه |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` | pay-per-token |
| OpenRouter | `https://openrouter.ai/api/v1` | هر مدلی که انتخاب کنید | pay-per-token + مدل‌های رایگان |
| Groq | `https://api.groq.com/openai/v1` | `llama-3.3-70b-versatile` | سهمیه رایگان + paid |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | ارزان |
| Ollama محلی | `http://127.0.0.1:11434/v1` | هر مدل نصب‌شده | رایگان (محلی) |

> قیمت‌ها/سهمیه‌ها را حتماً از سایت رسمی سرویس بررسی کنید؛ این جدول فقط ساختار تنظیم است و مبلغ دقیق ادعا نمی‌کند.

## انتخاب اقتصادی

- برای شروع: مدل‌های flash/mini یا Ollama محلی — کیفیت خوب برای عنوان/متا/FAQ با هزینه نزدیک صفر.
- برای مقاله کامل بلند: مدل‌های قوی‌تر (gpt-4o، glm-4-plus، deepseek-chat) بهترند.
- تسک‌ها به‌ازای هر فراخوانی توکن مصرف می‌کنند؛ خروجی‌ها همیشه با برچسب «AI — بازبینی کنید» نمایش داده می‌شوند.

## نکات امنیتی

- کلید فقط در سرور ذخیره می‌شود (AES-256-GCM) و در UI ماسک می‌شود.
- برای تیم، از کلید سرویس با سقف هزینه (budget) استفاده کنید.
- بدون تنظیم، همه تسک‌های AI پیام شفاف «تنظیم نشده» می‌دهند — هیچ خروجی ساختگی تولید نمی‌شود.

## تست اتصال

دکمه «تست اتصال» یک درخواست واقعی (`ping` با max_tokens کم) می‌زند و نتیجه/خطای واقعی provider را نشان می‌دهد.
