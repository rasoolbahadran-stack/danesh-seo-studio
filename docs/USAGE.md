# راهنمای استفاده

## گردش کار پیشنهادی (از ایده تا انتشار)

```
۱. تحقیق کلمات کلیدی → ۲. بریف محتوا (ویرایش + تأیید) → ۳. ساخت مقاله از بریف
→ ۴. نوشتن در ویرایشگر با امتیاز زنده → ۵. تحلیل رقبا + تکمیل گپ‌ها
→ ۶. Audit نهایی → ۷. رفع ایرادات بحرانی → ۸. انتشار + اتصال به سایت
```

## داشبورد

- وب‌سایت فعال را از بالای صفحه عوض کنید — همه ماژول‌ها روی همان ورک‌اسپیس کار می‌کنند.
- میانگین امتیاز، تعداد مقالات و گزارش‌های اخیر در نگاه اول.

## ویرایشگر

1. **نوار تنظیمات بالا**: عنوان، کلمه کلیدی اصلی/فرعی، عنوان سئو، توضیحات متا، وضعیت مقاله.
2. **Toolbar**: هدینگ‌ها، بولد/ایتالیک، لیست، جدول، لینک (انکرتکست توصیفی بنویسید!)، تصویر (Alt الزامی)، دکمه‌های 🤖 (عنوان/متا/بازنویسی/گسترش/خوانایی/نگارش)، Undo/Redo، پیش‌نمایش.
3. **ذخیره خودکار**: بعد از ~۲ ثانیه سکوت؛ Ctrl+S ذخیره دستی + نسخه.
4. **پنل راست**: گیج امتیاز + ۱۳ معیار رنگی؛ تب‌ها: ایرادات (کلیک = پرش به متن)، کلمات (چیپ سبز/قرمز)، خوانایی، لینک‌ها، متا (پیشنهادها با کلیک اعمال می‌شوند)، گوگل.
5. **نسخه‌ها**: هر ۵ دقیقه خودکار نسخه؛ بازیابی امن (نسخه امنیتی می‌سازد)؛ مقایسه با فعلی (بلوک‌های +/-).

## تحقیق کلمات

- Seed بدهید → long-tail، سوالات، خوشه‌ها. نکته provenance بالای نتایج را بخوانید (واقعی vs برآورد).
- تب **Mapping**: کلمات را به مقالات اختصاص دهید؛ تداخل‌ها قرمز می‌شوند.
- تب **کانیبالیزیشن**: مقالات هم‌کلمه را می‌گیرد و راه‌حل می‌دهد.

## رقبا

- تا ۵ آدرس واقعی بدهید → ساختار/حجم/واژه‌های کلیدی هر رقیب + پوشش معنایی مقاله شما + موضوعات جاافتاده.

## بریف

- تولید → ویرایش (سرفصل‌ها را اضافه/حذف کنید) → تأیید → از صفحه مقالات، مقاله از روی بریف بسازید.

## سئو تکنیکال

- URL صفحه واقعی → ۲۰+ بررسی (HTTP، canonical، robots، sitemap، OG، schema، noindex، تصاویر، لینک شکسته…)
- تب دوم: مقایسه چند URL برای محتوای تکراری.

## تنظیمات وب‌سایت

- **وزن امتیازدهی**: مثلاً برای مقالات خبری وزن خوانایی را بالا ببرید.
- **AI**: Base URL/مدل/کلید → تست اتصال.
- **SERP**: DataForSEO یا SerpApi.
- **اعضا**: نقش‌ها viewer/editor/admin.
- **share-token**: برای ویجت عمومی؛ بعد از استفاده می‌توانید بچرخانید.

## اتصال به سایت واقعی

- وردپرس: افزونه را نصب کنید؛ در تنظیمات وب‌سایت، connection = REST Contract با آدرس سایت + Application Password.
- Astro/Next: بسته‌های integration؛ جزئیات در `docs/CONNECTORS.md`.
- هر سایت دیگر: همان قرارداد REST را در بک‌اند خودتان پیاده کنید.
